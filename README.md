### 🏎️ Current Focus: ARIS
**World models + Reinforcement Learning for autonomous racing.**

*Most RL racing work optimizes lap time on a fixed simulator — the agent never learns **why** the car behaves the way it does. ARIS flips that: the agent learns a latent simulator of tire degradation, grip, and corner dynamics, then plans inside its own dream. The goal is sample-efficient racing intelligence that transfers across tracks instead of overfitting to one.*

**The Roadmap:**
*   **Phase 1 (Current):** Foundations — environment, baselines, and latent dynamics model.
*   **Phase 2:** Policy learning inside the learned simulator.
*   **Phase 3:** Transfer and evaluation across tracks.

**The Stack:** PyTorch → JAX/Flax | CUDA 12.x (RTX 5070) | Ollama (Llama 3.1 8B)
